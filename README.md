# VortexTech Cybersecurity Internship — Week 4 (Advanced)
## Mini Incident Response Plan

## What this is

This repository contains a mini Incident Response (IR) plan built around a hypothetical data-breach scenario, written for Week 4 of the VortexTech Cybersecurity Internship Track.

The scenario: a fictional e-commerce company (**BrightCart**) accidentally deploys an unauthenticated internal API endpoint that exposes ~250,000 customer records. The plan walks through the full response using the **NIST Incident Response Lifecycle**:

1. Preparation
2. Detection & Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

It also includes an internal communication plan (who gets notified, and when) and three preventative measures tied directly to the root cause.

## How to "run" it

This is a documentation/planning exercise, not code — there's nothing to execute. To review it:

1. Open [`incident-response-plan.md`](./incident-response-plan.md) to read the full plan.
2. Each section maps 1:1 to a phase of the NIST IR lifecycle, so it can be read top to bottom as a real response would unfold.

## Framework reference

Based on [NIST SP 800-61: Computer Security Incident Handling Guide](https://csrc.nist.gov/pubs/sp/800/61/r2/final).
